# Code of Conduct

## Our standard

Be respectful, specific and constructive. Disagreement about code, design or project direction is welcome; harassment, discrimination, personal attacks and deliberate disruption are not.

## Scope

This applies to project repositories, issues, pull requests, discussions and other project-managed community spaces.

## Enforcement

Maintainers may edit, hide or remove content and may restrict participation when behavior materially harms contributors or the project. Serious security reports should use the private vulnerability reporting path described in `SECURITY.md` rather than a public issue.
